# YOLO 기반 드론 산불 감지 시스템 | Capstone Project

Utah Valley University 전기·컴퓨터공학과에서 수행한 팀 캡스톤 프로젝트입니다. 사막 지형에서 촬영한 드론 RGB 이미지로 산불을 식별하고 두 탐지 모델의 성능을 비교했습니다.

## 참여 역할

조선신은 팀원들과 YOLOv8M과 YOLOv11L의 산불 탐지 성능을 비교했습니다.

## 실험 결과

팀은 이미지 25,656장을 학습 7,483장, 검증 8,552장, 시험 9,621장으로 분할했습니다. YOLOv8M은 50에포크 학습에서 mAP@50 86.1%, 재현율 79.4%를 기록했습니다. YOLOv11L은 150에포크 학습에서 mAP@50 92.1%, 재현율 96.0%를 기록했습니다. 두 결과는 서로 다른 학습 조건에서 얻었습니다.
